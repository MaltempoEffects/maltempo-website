Maltempo Effects Website

A small website where I'll be able to present my work as a sound recordist and sound designer. It will feature free downloadable sound effect libraries. Nothing revolutionary, there are already many sites like this, but I want to share my work, perhaps start a collaboration with someone in need of a sound designer and give something away for free. 

Since I'm making the website myself this will also present my current capabilities(or lack thereof) as a front end developer. I'm going to be using HTML, CSS and a bit of Javascript.
